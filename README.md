# ScriptSage AI

An AI-powered project exploring OCR for historical Devanagari manuscripts.

## Project Goal

Build a web application that helps users extract and review text from historical manuscript images.

## Planned Features

- Upload a manuscript image
- Extract Devanagari text using OCR
- Review and edit extracted text
- Export transcriptions

## Project Structure

- `frontend/` — Web interface
- `backend/` — API and processing logic
- `data/` — Sample data and evaluation assets
- `docs/` — Documentation

## Development Status

Initial project setup complete. OCR model selection, evaluation, and implementation are pending.

## Technology Stack

- Python
- FastAPI
- Next.js (planned)
- OCR model to be selected and evaluated

## Important Note

This is a development project. OCR results will require evaluation, especially for damaged manuscripts, historical spellings, and unusual handwriting.
